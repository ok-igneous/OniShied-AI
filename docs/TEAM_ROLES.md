# Founding Team Roles and Working Agreement

## Initial team shape

Start with three accountable contributors rather than recruiting five people before the work requires them.

### Founder / Product Lead
- Owns product direction, user discovery, scope, priorities, and competition strategy.
- Maintains the decision log and resolves product trade-offs.
- Coordinates contributors and ensures agreements are documented.
- Does not override security findings without evidence and review.

### AI / Backend Engineer
- Owns ingestion services, event schemas, orchestration, APIs, data model, and AI investigation workflow.
- Implements schema validation, tool boundaries, observability, and tests.
- Documents model limitations and provider dependencies.

### Cybersecurity Engineer
- Owns threat modelling, detection strategy, security test design, response risk tiers, and lab safety.
- Reviews permissions, action policies, and security-sensitive pull requests.
- Ensures all testing remains authorized and reproducible.

### Later roles, when justified
- Frontend / Platform Engineer: operator dashboard, mobile experience, deployment, and integration.
- QA / Research / Competition Support: test automation, reproducible scenarios, evidence collection, and demo readiness.

## Working rules

- Every task has one owner, acceptance criteria, and a target date.
- Work is tracked in GitHub issues and pull requests.
- No shared personal passwords or long-lived tokens.
- Use individual GitHub accounts and least-privilege repository access.
- Security-sensitive changes require relevant review.
- No one tests systems without explicit authorization.
- The founder owns product prioritization; technical and security decisions must be evidence-based.

## Compensation and ownership

This is an early-stage, bootstrapped effort. Do not imply guaranteed salary, equity, prize allocation, or future revenue share unless a separate written agreement has been reviewed and signed by the relevant parties. Define intellectual-property ownership, pre-existing work, confidentiality, vesting (if applicable), departure terms, and prize eligibility before accepting substantial contributions.

Prize proceeds and equity are separate matters and must follow competition rules, applicable law, and written agreements.
